# AnalystLab Africa - Week 1 Data Science Project
## ShopSmart Retail Analytics: Exploratory Data Analysis & Feature Engineering

### Project Overview
This repository contains the complete Week 1 Data Science project for **ShopSmart Retail Analytics**. The project analyzes enterprise-wide retail operations across 9 datasets covering 50,000 orders, 5,000 customers, 500 products, and 25 stores.

### Deliverables
- `Week1_EDA.ipynb`: Fully documented Jupyter Notebook covering Data Cleaning, EDA, KPIs (\$7.58B Revenue), Visualizations, Correlation Analysis, Feature Engineering, and Business Insights.
- `Cleaned_Data/`: Exported cleaned relational CSV datasets.
- `requirements.txt`: Python environment dependencies.
